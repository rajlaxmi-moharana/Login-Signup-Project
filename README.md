# Login & Signup UI Project

## 📌 Overview

This project is a responsive **Login and Signup User Interface** built using **HTML** and **CSS**. It features two interconnected pages with a clean, modern design and a user-friendly layout.

## ✨ Features
Login page
Signup page
Navigation between Login and Signup pages
Responsive layout
Organized project structure

## 🛠️ Built With

* HTML5
* CSS3
* Font Awesome

## 📁 Project Structure
